# FLUTML
 **全名 Flut Minecraft Launcher** 

## 项目概况
一款使用 Flutter 开发的 Minecraft 启动器，支持：
- **Java 版本管理**：自动检测并下载所需 Java 版本
- **多版本支持**：Vanilla、Forge、Fabric 版本
- **设计语言**：遵循 **Material You** 风格
- **开源协议**：本项目使用 **GPL-3.0** 协议开源

## 快速开始
1. 运行 `flutter pub get`
2. `flutter run` 启动启动器
- 本项目仅对 **Windows** 进行适配，待开发
