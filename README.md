## 介绍

FLUTML 是一款开源的 Material Design 3 Minecraft 启动器，支持模组管理、ModLoader 安装（Forge、Fabric）、模组资源下载、联机等功能。

## 下载

[GitHub 上的最新发行版](https://github.com/npickaxe11/FlutML/releases/latest/)
<br>
[Gitee 上的最新发行版](https://gitee.com/npickaxe11/flut-ml/releases/latest/)

## 开始

1. 运行 `flutter pub get`
2. `flutter run` 启动启动器
- 本项目仅对 **Windows** 进行适配，待开发
